# 냠냠클럽 구독자 랜딩 페이지 (학습용 샘플)

앱 내 광고를 눌렀을 때 보이는 구독자 전용 랜딩 페이지 예시입니다.
**"냠냠클럽"은 학습 목적으로 만든 가상 브랜드이며 실제 서비스와 무관합니다.** 혜택 수치도 모두 예시입니다.

- 페이지: `docs/index.html` (단일 HTML, 외부 의존성 없음)
- 스크린샷: `screenshots/` (280 / 390 / 768 / 1440px)
- 버전 기록: `VERSION.md`
- 배포: GitHub Pages (`.github/workflows/pages.yml`, `docs/` 폴더)
