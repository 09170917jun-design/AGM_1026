궁금한 점

구독 기간은 어떻게 계산되나요?

최초 구독 시작일부터 연속된 구독 개월 수로 계산해요. 해지 후 재가입하면 새로 시작돼요.

페이백 포인트는 언제 들어오나요?

매월 초 전월 주문 금액을 집계해 적립해요. 월 최대 20,000P까지 적립되며, 포인트 내역에서 확인할 수 있어요.

포인트 유효기간이 있나요?

적립일로부터 일정 기간 내 사용 가능해요. 정확한 기간은 포인트 내역에서 확인해 주세요.

구독을 해지하면 혜택은 어떻게 되나요?

해지 시점 이후 예정된 혜택은 지급되지 않아요. 이미 지급된 쿠폰·상품권·포인트는 유효기간 내 사용 가능해요.
